# Homepage
The design features several static elements with a focus on informative representation. For this homepage, we maintain the blue and white colors in most cases. Although there are several aspects that were carried on to the final design, many things had to be changed for the final design. 

## Problems
There is a substantial lack of transitions. Additionally, the pages are too descriptive, which takes up a lot of space. A lack of consistency in the design is also visible. The black color breaks the color scheme of the homepage. In the final design, we will implement these changes with detailed animations as well.
