# OceanBridge
A global maritime logistics and fleet management platform. Features vessel registration, fleet management, vessel tracking, voyage monitoring, and cargo management interfaces, designed in Figma and developed using modern front-end technologies.

## Project Overview
OceanBridge aims to connect global shipping operations through a centralized platform where users can manage vessels, monitor voyages, track shipments, and oversee maritime logistics.

This repository contains the frontend implementation of the OceanBridge platform.

## Design Process
*Initial Design*. First concept and layout exploration.

*Design Iterations*. Selected versions and refinements based on layout, usability, and visual consistency.

*Final Design*. The finalized interface after reviewing and refining the design.
